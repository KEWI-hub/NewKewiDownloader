Prism

One beam.
Many rays.

A download manager that splits every file into parallel segments — and a visual language built on the same idea: calm obsidian surfaces, liquid glass for the chrome, and a single spectral accent that only appears where light is actually moving.

Liquid glassObsidian solidsDense, calm dataSpectral segmentsInter + JetBrains Mono
01

Colour

Neutrals carry 95% of the UI. Accents are user-selectable; status colours are fixed and never re-mapped by the accent.

02

Materials

Glass is reserved for chrome that floats over something: sidebar, toolbar, status bar, dialogs, menus. Data lives on solid obsidian.
