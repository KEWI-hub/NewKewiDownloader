# New Kewi Downloader — ส่วนขยายเบราว์เซอร์

โหลดวิดีโอจากหน้าเว็บเป็น **.mp4** โดยทำทุกอย่างในเบราว์เซอร์ ไม่ต้องมีโปรแกรมข้างนอก

## ติดตั้ง

```bash
node extension/build.mjs
```

แล้วเปิด `chrome://extensions` → เปิด **โหมดนักพัฒนาซอฟต์แวร์** → **โหลดส่วนขยายที่แตกไฟล์แล้ว**
→ เลือกโฟลเดอร์ `dist/newkewi-extension`

## ใช้งาน

- **เอาเมาส์วางบนตัวเล่นวิดีโอ** → มีแผงโผล่มา เลือกความชัดแล้วกดโหลด
  ชื่อไฟล์ที่จะได้โชว์ไว้บนแผง ลงท้าย `.mp4` ตรงกับของจริงที่เซฟ
- **ปุ่ม "ทั้งหน้า"** → โหลดทุกคลิปในหน้านั้นลงโฟลเดอร์เดียวใต้โฟลเดอร์ดาวน์โหลด
- **เมนูของส่วนขยาย** → รายการที่ดักได้ · คิวงานพร้อมความคืบหน้า · บันทึกเหตุการณ์

โหลดพร้อมกันสองคลิป และแต่ละคลิปดึง segment ขนาน 6 ช่อง

## เวลาโหลดไม่ได้ ให้ส่งบันทึกมา

กด **"เก็บบันทึกเป็นไฟล์"** ในเมนูของส่วนขยาย ได้ไฟล์ที่

```
<โฟลเดอร์ดาวน์โหลด>/NewKewi-log/log-<วันเวลา>.txt
```

**งานที่ล้มเหลวจะเก็บบันทึกให้เองอัตโนมัติ** ไม่ต้องจำว่าต้องกดอะไร

ในบันทึกมีลิงก์ที่ดักได้ทุกตัว (พร้อมป้ายว่าตัวไหนเป็นโฆษณา) หัวคำขอที่ใช้ ขั้นของงาน
คำสั่ง ffmpeg และข้อความผิดพลาด · **ไม่มี cookie หรือค่ายืนยันตัวตนอยู่ในนั้น**

## ทำงานยังไง

```
ดักเน็ต (webRequest)          เจอ .m3u8 / .mp4 และ **จดหัวคำขอจริงที่หน้าเว็บส่ง**
      ↓
คิวงาน (background.js)        สวมหัวคำขอชุดนั้นให้คำขอของเราด้วย declarativeNetRequest
      ↓
ดึง segment (worker)          ขนานหลายช่อง · เรียงลงไฟล์เดียวใน OPFS · ทำต่อจากที่ค้างได้
      ↓
แปลง (mux.js)                 MPEG-TS → mp4 แบ่งท่อน (เฉพาะ segment ที่เป็น .ts)
      ↓
รวม (ffmpeg wasm)             `-c copy` → mp4 ปกติ
      ↓
เซฟ (chrome.downloads)
```

**ทำไมต้องโหลดในเบราว์เซอร์:** คำขอที่ออกจากที่นี่เป็นคำขอของ Chrome จริง ได้ cookie
ของเว็บนั้นและลายนิ้วมือ TLS ของเบราว์เซอร์ครบ เว็บที่กันบอทจึงมองว่าเป็นคนดูธรรมดา
ต่างจากการให้โปรแกรมข้างนอกยิงเอง ซึ่งโดนปฏิเสธทั้งที่เบราว์เซอร์เปิดหน้าได้ปกติ

**ไม่เข้ารหัสวิดีโอใหม่เลย** ทุกงานใช้ `-c copy` และตัว ffmpeg ที่ติดมา**เข้ารหัสอะไรไม่ได้**
จึงไม่มีทางได้ H.265 ออกมา · เลือกความชัดสูงสุดที่เล่นได้เสมอ (ข้าม variant ที่เป็น H.265/AV1)

**ไม่แตะ cookie ของผู้ใช้ในแง่ที่จะอ่านออกมาเก็บไว้** — เบราว์เซอร์แนบของมันเองตอนยิงคำขอ
เท่านั้น ส่วนหัวคำขอที่เราจดไว้มีแค่ Referer / Origin / User-Agent

## ยังทำไม่ได้

- **DASH (.mpd)** — ตัวแยกสตรีมที่ติดมาอ่าน `.mpd` ไม่ได้
- **สตรีมสด** — ไม่มีจุดจบให้โหลด
- **เว็บที่ซ่อนลิงก์ไว้ในหน้า ไม่ยิงผ่านเน็ตตรงๆ** — ต้องแงะหน้าเว็บ ไม่ใช่ดักเน็ต

## เทส

```bash
node extension/test/run-selftest.mjs             # เครื่องยนต์ กับสตรีม HLS จริง
node extension/test/run-smoke.mjs                # ตัวที่ build แล้วติดตั้งขึ้นไหม
node extension/test/run-livesite.mjs <url>       # ทั้งสายกับเว็บจริง
```

เทสทั้งหมดขับ Chromium จริงผ่านสายดีบั๊ก เพราะชั้นที่ต้องทดสอบ (OPFS, ffmpeg wasm,
fetch ข้ามโดเมนแบบมี cookie, declarativeNetRequest) ไม่มีอยู่นอกเบราว์เซอร์
