# New Kewi Downloader — ส่วนขยายเบราว์เซอร์

แปะปุ่มโหลดลอยไว้เหนือตัวเล่นวิดีโอ แบบที่ IDM ทำ · กดแล้วส่งเข้าคิวของแอปทันที เลือกความชัดได้ด้วย

## ติดตั้ง

1. เปิดแอป **New Kewi Video Downloader** ค้างไว้
2. ในเบราว์เซอร์เปิด `chrome://extensions` → เปิด **Developer mode** → **Load unpacked** → เลือกโฟลเดอร์นี้
3. เปิดหน้าเว็บที่มีวิดีโอ แล้วเอาเมาส์ไปวางบนตัวเล่น → แผงจะโผล่มุมบนขวา
4. กดโหลดครั้งแรก แอปจะเด้งถามว่า "ส่วนขยายขอเชื่อมต่อ" → กดอนุญาต (ครั้งเดียวจบ)

> Chromium พกพาที่แอปใช้เองก็โหลดส่วนขยายนี้ให้อัตโนมัติ ไม่ต้องติดตั้งซ้ำ

## ใช้ยังไง

- **เอาเมาส์วางบนวิดีโอ** → แผงโผล่ พร้อม dropdown ความชัด → กด "โหลด"
- **กดไอคอนบน toolbar** → เห็นรายการวิดีโอทั้งหมดที่ดักได้ในแท็บนั้น
- ดักอะไรไม่เจอก็ยังมีปุ่ม **"ส่งทั้งหน้าให้แอปแกะเอง"** ซึ่งให้แอปใช้ config ของเว็บหรือทางทั่วไปจัดการต่อ

## วิธีทำงาน

| ไฟล์ | หน้าที่ |
|---|---|
| `background.js` | ดัก request ที่เป็น `.m3u8` / `.mpd` / วิดีโอ แยกเก็บตามแท็บ · แตก master playlist เป็นรายการความชัด · คุยกับแอป |
| `content.js` | แผงลอยเหนือวิดีโอ · อยู่ใน **shadow root** เพื่อให้ CSS ของเว็บเจ้าบ้านทับไม่ได้ |
| `popup.html` / `popup.js` | รายการวิดีโอของแท็บนั้น + สถานะการเชื่อมต่อกับแอป |
| `panel.css` | กฎของตัวครอบแผงเท่านั้น (ตำแหน่งกับ z-index) |

## ความปลอดภัย

ส่วนขยายคุยกับแอปผ่าน `http://127.0.0.1:47800` ซึ่ง:

- ฟังเฉพาะ **loopback** เครื่องอื่นในวงแลนต่อเข้ามาไม่ได้
- ทุกคำขอต้องมี **token** ที่แอปสุ่มไว้ · หน้าเว็บทั่วไปไม่มีทางรู้
- ต้องมีหัว `X-NewKewi: 1` ซึ่งฟอร์ม HTML ธรรมดาส่งไม่ได้ (ต้องผ่าน CORS preflight) จึงกัน CSRF
- **การขอ token ครั้งแรกต้องให้ผู้ใช้กดอนุญาตในแอปเอง** ไม่มีทางได้มาเงียบๆ

**ส่วนขยายไม่ส่ง cookie ของคุณให้แอป** และฝั่งแอปก็ตัดหัว `Cookie` ที่ส่งมาทิ้งเสมอ
แอปใช้ cookie ของเบราว์เซอร์ตัวเองเท่านั้น

## ข้อจำกัดที่รู้อยู่

- วิดีโอที่เล็กกว่า 240×140 พิกเซลจะไม่มีแผงขึ้น เพราะมักเป็นภาพตัวอย่างหรือโฆษณา
- ลิงก์ที่หมดอายุเร็ว (บาง CDN ให้เวลาไม่กี่นาที) ถ้าส่งแล้วไม่โหลดทันทีอาจใช้ไม่ได้
  กรณีนี้ให้ใช้ "ส่งทั้งหน้าให้แอปแกะเอง" แทน แอปจะขอลิงก์ใหม่ตอนเริ่มโหลด
- คลิปที่มี DRM โหลดไม่ได้ ไม่ว่าทางไหน
